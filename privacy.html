Privacy e dati locali

Versione dell’app: 1.0 · Informazioni aggiornate al 27 ottobre 2026.

Un laboratorio senza account

Questa applicazione non richiede registrazione, non contiene pubblicità, strumenti di analisi delle visite o sistemi di profilazione. Il codice dell’app non invia a Claudia Bartoli o a un server le creazioni, le risposte o i progressi. Non utilizza cookie propri, font remoti, video incorporati o librerie caricate da servizi esterni.

Che cosa viene salvato nel browser

Per permetterti di continuare il gioco, l’app utilizza la memoria locale del browser (localStorage). Conserva automaticamente il lavoro in corso: posizione e orientamento dei pezzi, modalità scelta, sfida, aiuti richiesti, colori, tratti del pennello, paesaggio e trasformazioni. Quando premi «Salva in galleria», conserva anche titolo, breve descrizione, data e anteprima del lavoro. Memorizza le sfide completate per non riproporle casualmente nella stessa raccolta.

Questi dati restano nel browser e nel profilo utilizzato, sul medesimo dispositivo e indirizzo del sito. Non vengono sincronizzati automaticamente. Restano fino alla cancellazione da parte tua o del browser. La navigazione privata, i limiti di memoria o le impostazioni del dispositivo possono impedirne la conservazione.

Come controllare e cancellare i dati

Nella Galleria puoi eliminare singole creazioni oppure usare «Cancella tutti i dati» per rimuovere i dati dell’app da questo browser. La cancellazione delle creazioni non riapre da sola le sfide già completate nella raccolta: per ripeterle usa «Riprova» oppure avvia una nuova raccolta dopo averle completate tutte. Puoi anche cancellare i dati del sito dalle impostazioni del browser.

«Esporta archivio» scarica un file JSON sul tuo dispositivo; «Importa archivio» legge un file da te selezionato, senza caricarlo su un server. Le immagini PNG e i file JSON esportati devono essere cancellati separatamente dalla cartella in cui li hai salvati. Dopo la cancellazione totale, il successivo utilizzo dell’app può creare un nuovo salvataggio locale.

Attenzione sui dispositivi condivisi

Chi usa lo stesso profilo del browser può vedere i lavori salvati. Nei titoli e nelle storie non inserire nomi e cognomi, contatti, informazioni sensibili o altri dati personali. Per l’uso scolastico, il docente accompagna i bambini nell’utilizzo e nella gestione degli eventuali file esportati.

Quando il sito è ospitato su GitHub Pages

La visita richiede una connessione al servizio di hosting. GitHub dichiara che GitHub Pages registra e conserva l’indirizzo IP del visitatore per finalità di sicurezza. Questa gestione tecnica è distinta dai progressi che l’app salva soltanto nel browser. Per maggiori informazioni consulta la Privacy Statement di GitHub e la documentazione di GitHub Pages.

Se l’app viene pubblicata presso un altro gestore, il responsabile della pubblicazione deve aggiornare questa sezione per descrivere l’hosting effettivamente utilizzato. Aprendo i collegamenti esterni presenti nelle pagine informative, si applicano le informative dei siti di destinazione.

Responsabilità della pubblicazione

Progetto didattico: Claudia Bartoli. L’app, nella configurazione distribuita, non prevede raccolta remota dei progressi né un servizio di assistenza che riceva dati personali. Eventuali raccolte aggiuntive, moduli, statistiche o invio dei lavori introdotti da chi pubblica richiedono una revisione delle informazioni e degli adempimenti pertinenti.
